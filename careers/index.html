Internship

技术开发实习生（React Native / 全栈方向）

岗位介绍

我们正在开发一款面向同城社交、本地活动和本地生活服务的移动端 APP，产品涉及内容发布、用户互动、活动报名、商家服务、推荐系统及线上交易等场景。

该岗位以 React Native 移动端开发为主，同时可以接触 Node.js 后端、数据库、自动化测试和 AI 辅助研发流程。

岗位职责

  1. 参与 iOS、Android 双端 APP 的功能开发和日常维护。
  2. 基于 React Native、Expo 和 TypeScript 完成页面及业务功能开发。
  3. 根据产品原型和 UI 设计稿，实现页面布局、交互效果和状态管理。
  4. 对接后端 API，完成登录、内容发布、评论、点赞、收藏、活动报名等功能。
  5. 协助排查 APP 崩溃、接口异常、页面兼容性和性能问题。
  6. 参与真机测试、功能回归测试和问题记录。
  7. 使用 Git 和 GitHub 参与代码提交、分支管理及 Pull Request 流程。
  8. 在指导下补充基础单元测试、接口测试或端到端测试。
  9. 协助完善技术文档、接口文档和开发规范。
  10. 使用 Codex、Cursor 等 AI 编程工具辅助开发、排查问题和提升研发效率。

任职要求

  1. 计算机、软件工程、电子信息、人工智能等相关专业在校生。
  2. 掌握 JavaScript 或 TypeScript 基础，理解变量、函数、异步编程和模块化开发。
  3. 了解 React 或 React Native，做过课程项目、个人项目或实际 Demo。
  4. 了解常见移动端页面开发方式，能够完成列表、表单、弹窗和数据展示等功能。
  5. 了解 HTTP、RESTful API、JSON 等基本概念。
  6. 会使用 Git 完成代码拉取、提交、分支切换和冲突处理。
  7. 具备基本的问题排查能力，能够根据日志、报错信息定位问题。
  8. 工作认真，有责任心，能够及时反馈开发进度和遇到的问题。
  9. 每周可实习至少 4 天，连续实习 3 个月及以上。

以下能力不要求全部具备

  • 使用过 React Native、Expo 或 Expo Router。
  • 使用过 React、Vue 等前端框架。
  • 了解 Node.js、Express 或 NestJS。
  • 了解 PostgreSQL、MySQL、Redis 等数据库或缓存。
  • 有 iOS、Android APP 真机调试经验。
  • 了解 Jest、Maestro、Playwright 等测试工具。
  • 了解 Docker、GitHub Actions 或基础 CI/CD 流程。
  • 有个人项目、GitHub 项目、课程设计或实习经历。
  • 使用过 Cursor、Codex、Claude Code 等 AI 编程工具。

实习期间可以获得

  1. 参与真实互联网产品从开发、测试到上线的完整流程。
  2. 接触 React Native、Expo、Node.js、PostgreSQL、Redis 等实际技术栈。
  3. 学习规范的 Git 分支、代码评审和 Pull Request 协作流程。
  4. 参与 iOS TestFlight、Android 测试包及应用上架相关工作。
  5. 接触用户系统、内容社区、活动、商家和交易等真实业务场景。
  6. 获得明确的任务拆解、代码指导和阶段性反馈。
  7. 表现优秀者可获得长期实习或正式岗位机会。

我们希望你是

  • 基础不一定非常全面，但愿意主动学习。
  • 遇到问题能够先尝试搜索、看日志和查文档。
  • 不隐瞒问题，能够及时同步风险和进度。
  • 对代码质量有基本要求，愿意接受 Code Review。
  • 对做出一款真实可用的 APP 有兴趣和成就感。

Internship

软件测试实习生

岗位介绍

我们正在开发一款本地生活社交 APP，包含内容发布、同城活动、用户互动、商家服务、团购和在线支付等功能。

现招聘一名软件测试实习生，参与 APP 的日常测试和质量保障工作。岗位前期以功能测试、接口测试为主，后续会根据个人能力逐步接触移动端自动化测试。

岗位职责

  1. 根据产品需求和设计稿，整理并执行测试用例。
  2. 负责 iOS、Android APP 的功能测试和回归测试。
  3. 测试登录注册、内容发布、评论点赞、活动报名、订单支付等业务功能。
  4. 使用 Apifox、Postman 等工具进行基础接口测试。
  5. 发现并提交 Bug，清楚描述问题现象、复现步骤和测试环境。
  6. 跟进 Bug 的修复情况，并完成修复后的验证。
  7. 协助整理测试文档、测试数据和常见问题记录。
  8. 在指导下学习和编写简单的自动化测试脚本。

任职要求

  1. 本科及以上学历，计算机、软件工程或相关专业在校生。
  2. 对软件测试或互联网产品质量工作感兴趣。
  3. 了解基本的软件测试流程和测试方法。
  4. 能够耐心、细致地发现问题，并清楚描述问题。
  5. 了解 HTTP、接口、数据库或编程基础中的任意一项。
  6. 具备良好的沟通能力、责任心和学习能力。
  7. 每周能够实习至少 3 天，连续实习 3 个月以上。

加分项

  1. 使用过 Apifox、Postman、Charles 等测试工具。
  2. 学习过 Python、Java、JavaScript 或其他编程语言。
  3. 有 APP、小程序、网站测试或个人项目经验。
  4. 了解 Git、SQL 或自动化测试工具。
  5. 平时经常使用小红书、美团、抖音等内容或本地生活类 APP，并能够从用户角度发现产品问题。

你将获得

  1. 参与一款 APP 从开发、测试到上线的完整过程。
  2. 接触真实的社交、内容、订单和支付业务场景。
  3. 学习功能测试、接口测试和移动端自动化测试。
  4. 与产品、设计和开发团队直接协作。
  5. 表现优秀者可获得长期实习或转正机会。

对以上岗位感兴趣，请发送简历至 anson@hooltech.com。
